# Contributing

Open an issue for a bug or proposed change. For bugs, include the app version,
Windows version, reproduction steps, and relevant log lines. Remove personal
paths and other private information before posting logs.

Keep pull requests focused and run the tests listed in the README. Add a test
when fixing behavior that can regress. Use plain, short UI labels.

Do not commit user settings, imported packs, Roblox files, credentials, or build
output. Contributions to the project are under its MIT license.
